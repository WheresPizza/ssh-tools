# SSH GUI 0.3.3 — stabilization candidate

**Draft candidate, not accepted as a stable release.** Native Terminal.app/adapter and the full installation, upgrade and UI acceptance matrix remain incomplete. Do not treat automated test passes as confirmation of those scenarios.

## Fixes

- Use system OpenSSH executables and one selected SSH agent for each operation. An explicitly unavailable agent is no longer silently replaced.
- Track encrypted-key enrollment through terminal completion and verify the fingerprint in the same agent. Opening a terminal is not reported as successful enrollment or authentication.
- Keep terminal operation results across restarts; retain action errors and failed dialogs, prevent overlapping import pickers and invalid diagnostic ports, and improve keyboard and scrolling behavior.
- Handle valid ECDSA keys with short private scalars and validate generated key pairs before publishing files.
- Show the actual running version, executable and selected agent in Settings.
- Seal macOS application bundles with an ad-hoc signature, Hardened Runtime and the Apple Events automation entitlement.
- Update source-map-js to resolve the npm audit finding. No new management features are introduced.

## Validation and remaining limitations

The recorded local checks passed: 91 frontend tests, 85 Rust tests (including isolated agent, controlling PTY and loopback SSH-server scenarios), production build and release metadata checks. Native terminal interaction, all supported terminal adapters and the full UI/upgrade matrix remain release blockers. Full-lockfile Rust dependency advisories are recorded in the acceptance report; this is not a clean cross-platform audit.

See the [acceptance matrix and limitations](https://github.com/WheresPizza/ssh-tools/blob/0.3.3/docs/releases/0.3.3-verification.md).

## Downloads

The attached DMG and app archive are for **macOS Apple Silicon (arm64)**. They contain the same verified application. SHA-256 checksums are attached as `SHA256SUMS`.

The application is ad-hoc signed, **not Developer ID signed or notarized**. macOS may block opening it. Automation permission is still controlled by macOS; this package does not grant it automatically.

Both packages were inspected for SSH keys and configuration data. No key records or SSH configuration files were found, and the disposable regression-test key is absent from the release binary. Private-key passphrases are entered in the terminal and are not stored in operation receipts.

# SSH GUI 0.3.1

Local patch in preparation; not published.

Repository access now belongs to the key. The standalone Repositories page is removed; existing scan folders remain available in key details. A saved Repositories tab opens SSH Keys after upgrading.

From a key’s details, choose a local repository, its remote and an existing Git profile for that key. Review the old and new URLs before applying. The writer checks configuration revisions and key identity, respects Git locks, refuses complex/conflicting configuration and saves a previous-config backup. Scans and audits remain read-only; setup performs no network authentication.

Git Profiles remains the owner of account aliases. Linked worktrees support discovery only; access setup supports regular repositories with one URL and no separate push URL. Global/environment overrides can still affect authentication.

macOS is the supported release target. Signing, packaging and publication must be validated separately before distribution.

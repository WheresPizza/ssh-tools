# SSH GUI 0.3.2

Includes the repository-access and navigation improvements developed as 0.3.1; these changes ship together in 0.3.2.

**Replace key references** is a four-step wizard in key details: select a new identity, choose explicit host/profile references, review changes and apply with recovery backups after acknowledging public-key registration. Existing keys, agent state, annotations, aliases and repository URLs remain unchanged.

The writer checks fingerprints and configuration revisions, stages changes and backups before modifying configuration, and attempts rollback on detected write failures. Ambiguous/global/Match/wildcard references and external includes require manual review. A multi-file update is not crash-atomic; Settings recovery provides a backup for each changed file. No remote key installation or authentication occurs.

macOS Apple Silicon (ARM64) build. The application has no Developer ID signature and is not notarized.

Validation: 80 frontend tests and 78 Rust tests, plus the complete native replacement workflow using disposable keys. npm audit reports no vulnerabilities. The cross-platform Cargo lockfile retains three documented advisories for quick-xml and optional rsa; neither package is in the current macOS dependency tree. See docs/BEHAVIOR.md for scope and limitations.

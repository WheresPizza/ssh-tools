# SSH GUI 0.3.0

Organize and inspect your local SSH keys without editing configuration files by hand.

## What's new

- **Key details:** fingerprint, private/public paths, local copies, passphrase state, agent membership and references from hosts, Git profiles and selected repositories.
- **Shared annotations:** tags, purpose, notes and a planned replacement date, stored separately from key files and shared by fingerprint.
- **Search and filtering:** find keys by tag or purpose and narrow the library to a selected tag.
- **Read-only local audit:** identify unencrypted keys, malformed/mismatched pairs, missing public companions, duplicate identities, excess permissions and missing local references. Project folders are scanned once per audit.
- **Safe editing:** stale annotation revisions and changed key identities are rejected; failed saves retain the draft.
- **Compact interface:** improved wrapping for card actions and search controls in small windows.

## Download and verification

macOS Apple Silicon (ARM64 / aarch64): use the DMG for installation, or the `.app.tar.gz` archive. `SHA256SUMS` contains the asset checksums.

These builds are **unsigned and not notarized**. There is no Intel, universal, Windows or Linux binary in this release.

Local verification: 73 frontend tests and 74 Rust tests passed, including real Tauri IPC with temporary keys, annotation persistence and audit checks that preserve SSH file bytes, permissions and modification timestamps. Native UI checks covered normal and minimum window sizes.

## Boundaries

The audit does not connect to servers, alter files or revoke keys. Missing local references do not prove a key is unused. Planned replacement dates are reminders, not key expiration. Notes are local plain text; do not store secrets in them.

`npm audit` reported zero vulnerabilities. The Cargo lockfile retains three previously documented findings affecting quick-xml 0.38.4 and optional rsa 0.9.10; neither is in the validated macOS dependency tree. Other upstream maintenance/unsoundness warnings remain documented in [Behavior and security boundaries](https://github.com/WheresPizza/ssh-tools/blob/v0.3.0/docs/BEHAVIOR.md).

## SSH GUI 0.2.0

A local macOS workspace for SSH keys, Git identities and connections, with a compact terminal-inspired interface.

### Highlights

- Separate work, personal and client Git accounts with profiles, dedicated SSH aliases and clone URLs.
- Discover local Git repositories and inspect which aliases, profiles and keys their remotes reference.
- Import existing keys, detect fingerprint duplicates and recover missing OpenSSH public keys.
- Set SSH-agent lifetimes and optional per-use confirmation.
- Inspect effective OpenSSH configuration and explicitly test authentication.
- Manage host rules, server trust, key permissions and previous-file recovery.
- Consistent monospace UI, new terminal-and-key icon and reorganized navigation. Connections live in SSH Hosts; terminal preferences and recovery live in Settings.

### Install

Download the `.dmg` matching the architecture in its filename, open it, and drag **SSH GUI.app** to Applications. `aarch64` means Apple Silicon. This release targets macOS; Linux and Windows are not validated.

**These builds are unsigned and not notarized.** macOS may block opening them.

### Important boundaries

Repository mappings are configured candidates, not proof of authentication. Profiles do not register keys with Git providers or rewrite remotes. Recovery retains one previous version of supported config/trust files and does not back up private keys. Key deletion does not revoke remote access.

The cross-platform Rust lockfile has documented quick-xml and optional rsa advisories that are absent from the verified macOS dependency tree, plus upstream maintenance warnings. Read the [behavior and audit notes](https://github.com/WheresPizza/ssh-tools/blob/v0.2.0/docs/BEHAVIOR.md).

# 0.3.1 local verification

Status: implemented locally on branch `0.3.1`; not committed, pushed, merged, tagged or published as part of this patch.

## Changes

Removed the separate repository catalogue and moved shared scan-folder coverage to key details. Existing settings are reused, and saved repository navigation migrates to SSH Keys. Added a narrow, reviewed workflow for setting an existing repository remote to an SSH profile assigned to the selected key. Git Profiles remains the owner of aliases.

## Passed checks

- Frontend: 77 tests across 8 files; TypeScript and Vite production build.
- Rust: 76 tests, including the isolated local lifecycle through real Tauri IPC.
- New access coverage: preview leaves configuration unchanged; apply preserves unrelated settings and writes a backup; stale revisions, wrong fingerprints, forged plans, occupied Git locks, SSH-command overrides, includes and multiple/push URLs are refused.
- URL parsing covers ordinary SSH/HTTPS paths and incompatible hosts, users, explicit ports, credentials and unsupported syntax.
- UI tests cover removed-navigation migration, scan-folder selection, profile filtering by key, explicit preview/apply and rejected edits.
- Cargo formatting, release metadata consistency and Git whitespace checks.
- Built a separate macOS debug preview app with bundle ID `io.github.wherespizza.ssh-tools.preview031` and an isolated temporary workspace. Native navigation shows version 0.3.1, no Repositories screen, and the new workflow in key details.

## Limits / remaining release work

The native folder-picker walkthrough was initially interrupted by user interaction. On the resumed attempt, the computer-use automation could set the folder path but Return/Escape reset the field to `/` instead of confirming or closing it; mouse activation also failed. Visual completion of preview/apply was therefore not verified. The same workflow passed frontend and real backend IPC checks separately. No real SSH files, user repositories or remote servers were used for verification.

This is not a release-candidate signing or distribution audit. No fresh dependency vulnerability audit, notarization, DMG packaging, GitHub workflow or publication was performed for this local patch. Before distribution, complete the native walkthrough and the release guide.

Setup intentionally refuses linked worktrees/submodules and complex Git overrides; their discovery stays read-only. Global Git/environment overrides and dynamic SSH rules are not an authentication guarantee. The `.git/.config.ssh-gui.bak` backup is separate from Settings recovery.

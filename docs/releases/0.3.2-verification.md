# 0.3.2 local verification

Pre-publication verification for `0.3.2`, including the 0.3.1 changes. This report records local evidence; GitHub CI and release artifact verification are separate publication gates.

## Passed checks

- 80 frontend tests across 9 files. The replacement workflow covers identity selection, explicit target selection, blocked rules, review, registration acknowledgement, apply, cancel and stale-plan refresh.
- 78 Rust tests. Real Tauri IPC checks selected main/included host directives and a Git profile; key/metadata preservation; stale configuration and changed-key rejection; forged and blocked selections; CRLF/comments; retained unselected references; backup discovery through existing Settings recovery.
- Simulated second-file write failure rolls back the first file while retaining recovery backups. Preflight refusal leaves every configuration file unchanged.
- TypeScript/Vite production build, native macOS debug app build, Cargo formatting, release metadata consistency and whitespace checks.
- Native preview completed all four steps with disposable keys in an isolated workspace: choose replacement, select profile and literal host, review before/after values, acknowledge the test prerequisite and apply. The wildcard rule was disabled. Success was shown and the old key’s reference list refreshed to contain only its unchanged wildcard reference.
- Filesystem verification confirmed the selected profile/host switched, the wildcard reference and both key files remained, and the backup contained the previous configuration. The native review layout was inspected at 1024×680.

## Limits

No real user keys/repositories or remote servers were modified. No remote public-key registration or authentication was tested. Multi-file updates are not crash-atomic; rollback is attempted on detected failures and concurrent external edits require manual recovery. Default/dynamic references and unsupported rules remain outside automatic replacement.

The previously documented 0.3.1 native folder-picker automation limitation is separate from the successfully completed replacement wizard. Small-window visual testing and signing/notarization were not performed. Release packaging and GitHub publication are separate release gates. Follow the release guide before distribution.

Fresh pre-publication dependency audits: npm reports zero vulnerabilities; Cargo reports the same three documented advisories (RUSTSEC-2026-0195, RUSTSEC-2026-0194 and RUSTSEC-2023-0071). The affected quick-xml 0.38.4 and rsa 0.9.10 packages are absent from the current macOS dependency tree.

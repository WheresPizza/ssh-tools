# Security

SSH GUI handles local authentication material. See [Behavior and security boundaries](docs/BEHAVIOR.md) for file handling, agent policies, diagnostic behavior and known dependency findings.

## Reporting

Do not include private keys, passphrases, tokens, production configuration or exploitable details in a public issue. If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, ask the maintainer for a private reporting channel without publishing the sensitive details. This repository does not currently advertise a dedicated security email or response-time guarantee.

Include the affected version, platform, impact and a minimal reproduction using disposable data. Version 0.2.0 is the current release candidate; fixes for older releases are not guaranteed. Linux and Windows are not validated release targets.
